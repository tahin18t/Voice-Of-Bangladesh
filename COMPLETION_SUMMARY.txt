## 🔌 API Integration Points

```
Login Page
  └─ handleLogin() → api.login()

Dashboard
  ├─ loadDashboardData() → api.getFeedbacks()
  ├─ viewFeedback() → api.getFeedback()
  ├─ assignFeedback() → api.assignFeedback()
  ├─ bulkAssign() → api.assignFeedback() × N
  └─ bulkUpdateStatus() → api.updateFeedbackStatus() × N

Submit Feedback
  └─ submitForm() → api.createFeedback()

Track Feedback
  └─ searchFeedback() → api.getFeedbacks()
```
